# Codex Windows Store Helper

[English: полная инструкция](README.md) · Русский: быстрый старт

Установка и обновление официального Windows-приложения OpenAI, когда Microsoft
Store или WinGet не справляются. Используется официальный подписанный MSIX;
скрипт проверяет подпись, издателя, архитектуру и совместимость Windows.

Это независимый проект сообщества. В репозитории нет перепакованного приложения.
Название пакета — `OpenAI.Codex`, хотя в актуальной документации OpenAI приложение
называется ChatGPT desktop app.

## Сначала проверь без установки

Нужны Windows 11, Windows PowerShell 5.1 и доступ к `persistent.oaistatic.com`.

1. [Скачай ZIP с исходниками](https://github.com/pavelbe/codex-windows-store-helper/archive/refs/heads/main.zip).
2. Распакуй архив и открой Windows PowerShell в полученной папке.
3. Выполни:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Update-Codex.ps1 -CheckOnly
```

Команда покажет установленную версию и метаданные официальной загрузки.
Она не скачивает приложение, не устанавливает его, не входит в аккаунт
и не удаляет данные. Метаданные сервера ещё не доказывают подлинность файла:
подпись проверяется после скачивания.

## Установить или обновить

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-Codex.ps1 -OpenApp
```

Для обновления уже установленного приложения:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Update-Codex.ps1
```

Запускай от своего обычного пользователя Windows: регистрация приложения
выполняется для текущего аккаунта. Пакет занимает сотни мегабайт; нужны сеть
и свободное место. Скрипт выбирает x64/Arm64, однако запуск на Arm64 ещё
не проверен вручную.

Повторная установка применяет пакет без предварительного удаления приложения
или его данных. Скрипт не сбрасывает авторизацию, не останавливает WSL и не
меняет прокси, права доступа или брандмауэр. Политики и службы установки
приложений Windows должны работать.

## Если возникла ошибка

- Файлы заняты (`0x80073D02`): сохрани работу, закрой приложение обычным способом
  и повтори попытку. Перезапускать WSL не требуется.
- Ошибка подписи: повторно скачай пакет из официального источника. Не отключай
  проверку подписи и не устанавливай сертификаты ради обхода ошибки.
- Доступ запрещён (`0x80070005`): проверь журнал AppX; этот код сам по себе
  не доказывает, что нужно запускать всё от администратора.

[Полная таблица ошибок и диагностика](README.md#if-deployment-fails).
[Сообщить об ошибке](https://github.com/pavelbe/codex-windows-store-helper/issues/new?template=installation.yml)
можно и по-русски. Укажи команду, Windows, архитектуру и краткую ошибку.
Не прикладывай `auth.json`, токены, историю сессий, личные пути и полные журналы.

Если инструмент помог, поставь звезду репозиторию — так его легче найти другим.
